Feasibility of physically based volumetric rendering for real-time applications

Eloi Pena Gómez 
MSc in Computer Games Technology (Abertay University), 2025

ABSTRACT

Volumetric VFX are widely used in films and games, but often as pre-baked static effects. While this approach can be sufficient in many cases, it prevents dynamic interaction and leads to higher memory consumption. On the other hand, a real-time solution fixes both of these issues with bandwidth and latency performance as a trade-off. The goal of this project is to research, validate and test a volumetric rendering pipeline with its corresponding volumetric representation and associated image model that is memory efficient, simple enough for the scope of this project and compatible with PBR or can be extended to implement it. The chosen approach is based on the novel one described by Condor et al. (2025), which employs kernel-based ellipsoid primitives as volumetric representation and a custom tracing algorithm that integrates transmittance along each ray as a mixture of the transmittance of the primitives intersecting it. In addition, they provide closed-form solutions for Gaussian and Epanechnikov kernels. Last but not least, in order to convert files in other volumetric representation to this specific one, the BoundedAdam optimizer is used to fit a cloud of primitives to the given volume. Regarding my own work, I have adapted this ellipsoid-based approach to the DirectX Raytracing (DXR) framework for the manageable case of purely absorptive participating media and with support for both Gaussian and Epanechnikov kernels. In addition, I have designed it to be compatible with the output from the optimizer stage, thus assembling a full pipeline from .vol file to primitive-based rendered volume. Five experiments have been carried out to validate each of the pipeline stages both individually and together. They also focus on testing differences between Gaussian and Epanechnikov kernels both visually and performance-wise.
